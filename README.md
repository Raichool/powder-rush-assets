# Powder Rush — assets v3
Démo : https://raichool.github.io/powder-rush-assets/demo/
- `out/rider_v3.glb` : le rider (14 012 triangles, 16 animations). Variantes de couleur : `_red`, `_green`, `_purple`, et `rider_palettes.json`.
- `out/decor/*.glb` : le décor, compressé en meshopt. Stats dans `decor_stats.json`.
- `build/` : les scripts Blender 4.2 headless (rider.py, decor.py, scene.py, render_rider.py).
